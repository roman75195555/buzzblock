# SeedRush (бывш. BuzzBlock)

Roblox-игра в стиле «Steal a Brainrot»: 3 базы игроков, центральная дорожка
с 7 локациями боссов (по карте-референсу), кража семян, погоня, прокачка
скорости и силы, пассивный доход с грядок.

## Геймплей

- **База**: беговая дорожка (+⚡ скорость), гантеля (+💪 сила за клик),
  4 грядки для семян (пассивный доход 💰/сек после выращивания).
- **Дорожка**: 7 цветных локаций, в каждой спит босс. Рядом — пьедесталы
  с семенами. Чем дальше локация, тем сильнее босс и ценнее семя.
- **Кража**: нужна сила ≥ требования локации. Украл семя — босс проснётся
  и погонится. Догнал — семя потеряно. Добежал до зелёной зоны — семя твоё.
- **Магазин** (кнопка в HUD): улучшение дорожки, тренажёра, следы (+скорость).

## Сборка и запуск

1. Установи [Rojo](https://rojo.space/) (или используй `tools/rojo.exe`).
2. Собери place-файл:
   ```
   tools/rojo.exe build -o SeedRush.rbxlx
   ```
3. Открой `SeedRush.rbxlx` в Roblox Studio и нажми **F5 (Play)**.
   Карта и объекты видны сразу; геймплей работает в режиме Play.

Для live-синхронизации: `tools/rojo.exe serve` + плагин Rojo в Studio.

## Структура

- `assets/Map.rbxm` — вся статичная карта из референса (3 базы, дорожка,
  арка, стены), извлекается из `reference_map.rbxl` скриптом
  `tools/extract_map.luau`.
- `assets/DumbbellTool.rbxm` — гантеля (тренажёр силы).
- `src/ReplicatedStorage/Modules/Config.lua` — все игровые числа.
- `src/ServerScriptService/` — DataService, EconomyService, BaseService,
  BossService, ShopService, Main.
- `src/StarterPlayerScripts/` — HUD и магазин.

Прогресс сохраняется через DataStore (`SeedRush_v1`).
