# BuzzBlocks

Красочная блоковая Roblox-игра (Luau): выращивай растения, собирай подлодку,
ныряй в подводный мир, кради семена у морских животных и разводи пчёл,
которые приносят пассивный доход. Вдохновлено стилем Grow a Garden / LEGO.

## Структура проекта

Проект построен на [Rojo](https://rojo.space/) — весь мир, модели, UI и логика
описаны кодом и синхронизируются в Roblox Studio.

```
src/
  ReplicatedStorage/
    Modules/
      Config.lua        -- вся балансная конфигурация: детали, животные, пчёлы, цены
      BuildUtil.lua     -- конструктор блочных моделей (LEGO-стиль: studs, glow, эмиттеры)
  ServerScriptService/
    Main.server.lua     -- точка входа: remotes, загрузка сервисов
    DataService.lua     -- DataStore: профиль, автосохранение, BindToClose
    EconomyService.lua  -- монеты, покупки (серверная валидация), пассивный доход
    WorldService.lua    -- карта: остров-хаб, магазин, лагуна, подводный мир
    BaseService.lua     -- базы игроков: поле, слоты грядок, стапель, декор
    SubmarineService.lua-- сборка подлодки из деталей, физика, винт, топливо, портал
    AnimalService.lua   -- морские животные: спавн, анимация плавания, кража семян
    PlantService.lua    -- посадка, стадии роста, цветение
    BeeService.lua      -- пчёлы: модель, полёт, взмахи крыльев, редкости и мутации
  StarterPlayerScripts/
    ClientMain.client.lua -- вход клиента: HUD, кнопки, подводные эффекты
    UI/HUD.lua          -- монеты, семена, уведомления
    UI/ShopUI.lua       -- магазин деталей
    UI/BuildUI.lua      -- верфь: выбор деталей и сборка подлодки
```

## Как запустить

1. Установи [Rojo](https://rojo.space/docs/v7/getting-started/installation/) (7.x).
2. В папке проекта выполни:

   ```bash
   rojo serve
   ```

3. В Roblox Studio открой пустой Baseplate, установи плагин Rojo и нажми **Connect**.
4. Весь код и мир загрузятся в Studio. Нажми **Play**.

> Сохранение прогресса (DataStore) работает только в опубликованной игре
> (File → Publish to Roblox) либо при включённом «Enable Studio Access to API Services».

## Геймплей

1. Каждому игроку выдаётся остров-база с полем на 6 грядок и стапелем.
2. В магазине (здание на хабе) покупаются детали 5 типов: корпус, двигатель,
   винт, топливный бак, руль — у каждой 4 уровня качества.
3. На стапеле собирается подлодка — она появляется в воде у понтона.
   Въехав в портальное кольцо, подлодка переносится в подводный мир.
4. Под водой — 7 локаций по прямой: коралловый сад, лес водорослей, руины,
   гроты, тёмный риф, ледяные чертоги и логово кракена. В каждой спит свой
   монстр, вокруг разбросаны яйца. Украл яйцо (E) — монстр просыпается
   и гонится за тобой, нанося урон подлодке. Доплыл до портала — спасён.
   Если корпус разбит, подлодка уничтожается. Чем дальше локация,
   тем ценнее яйцо и тем сильнее монстр.
5. На базе семя из яйца сажается в грядку. Растение проходит 4 стадии роста.
   Нажми на выросший цветок — получишь пчелу.
6. Растения и пчёлы приносят монеты каждую секунду. На доход пчелы влияют
   редкость, мутация (Gold / Crystal / Rainbow) и размер.

## Управление

- **WASD / стик** — движение; в подлодке — вперёд/назад и поворот.
- **R / F** — всплытие и погружение подлодки (на телефоне — кнопки ▲▼).
- **Space** — выпрыгнуть из подлодки.
- **E** — взаимодействие (яйца, сбор пчелы, посадка).
- Полностью поддерживаются сенсорные экраны (кнопки UI и ProximityPrompt).

## Технические решения

- Все действия с экономикой валидируются на сервере (RemoteFunction/RemoteEvent
  с проверкой денег, инвентаря и расстояний).
- Физика подлодки: `VehicleSeat` + `LinearVelocity` + `AlignOrientation`,
  винт на `HingeConstraint` с мотором.
- Анимации процедурные: крылья пчёл, хвосты рыб, рост цветов, пузыри.
- Автосохранение каждые 120 с + сохранение при выходе и `BindToClose`.
