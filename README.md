# Lunar Base (бывш. BuzzBlock / SeedRush)

Roblox-tycoon про лунную базу: 6 игроков, у каждого свой участок с конвейером.
Лунные камни едут по ленте, лазер перерабатывает их в кредиты, кредиты
накапливаются на терминале — забери их, встав на зелёную площадку.

## Геймплей

- **Лунный мир**: серая поверхность с кратерами и валунами, холмы, чёрное
  звёздное небо, Земля с материками и облаками на горизонте, лунная пыль,
  пониженная гравитация.
- **6 участков** с неоновой рамкой территории и табличкой владельца.
- **Конвейер**: металлическая рама, ролики (вращаются), камни физически
  едут по ленте.
- **Лазер**: в конце ленты перерабатывает камень — вспышка, частицы, кредиты
  летят на терминал.
- **Терминал**: экран с накопленной суммой; встань на зелёную площадку —
  деньги переведутся тебе.
- **Кнопки покупок на полу** (последовательные): новые конвейеры, лазеры
  Mk.II/III/Солнечный (x2/x3/x5), ускорители лент, жилой модуль-купол,
  лаборатория с антенной. Каждая покупка реально строится на базе.
- Прогресс сохраняется (DataStore `LunarBase_v1`), базы игроков независимы.

## Сборка и запуск

```
tools/rojo.exe build -o LunarBase.rbxlx
```

Открой `LunarBase.rbxlx` в Roblox Studio и нажми **F5 (Play)**.
Для live-синхронизации: `tools/rojo.exe serve` + плагин Rojo в Studio.

## Структура

- `src/ReplicatedStorage/Modules/Config.lua` — все игровые числа и улучшения.
- `src/ServerScriptService/` — DataService, WorldService (луна), BaseService
  (участки, конвейеры, лазер, терминал, кнопки), Main.
- `src/StarterPlayerScripts/` — HUD.

Архитектура сервисная: новые постройки добавляются записью в
`Config.Upgrades` + ветка в `BaseService.ApplyUpgrade`.
